MULTIJOUEUR EN LIGNE · 1 CONTRE 1
📴 Hors ligne : le multijoueur nécessite une connexion Internet. Tu peux jouer en solo contre l'IA.
Économie : les ressources arrivent en flux continu. Construis des Extracteurs sur les gisements (taches métalliques) et des Générateurs pour l'énergie. Une construction avance seulement si tu as de quoi la payer.
Mobile : touche une unité pour la sélectionner, touche le sol pour la déplacer, touche un ennemi pour l'attaquer. Glisse pour déplacer la caméra, pince pour zoomer. ▢ Boîte = sélection de zone. Double-touche = toutes les unités du même type.
PC : clic gauche / glisser = sélection, clic droit = ordre, molette = zoom, clic molette ou flèches = caméra, A = mode attaque, S = stop, Maj = file d'ordres, Échap = annuler.
Multijoueur : un joueur crée la partie et donne le code à l'autre, qui le saisit puis touche « Rejoindre ».
Défaite : si ton Architecte meurt, la partie est perdue.
