FRONT D'ACIER

Stratégie temps réel. Développe ton économie, construis une armée et détruis l'Architecte ennemi avant qu'il ne détruise le tien.
Économie : les ressources arrivent en flux continu. Construis des Extracteurs sur les gisements (taches métalliques) et des Générateurs pour l'énergie. Une construction avance seulement si tu as de quoi la payer.
Mobile : touche une unité pour la sélectionner, touche le sol pour la déplacer, touche un ennemi pour l'attaquer. Glisse pour déplacer la caméra, pince pour zoomer. Active ▢ Boîte pour sélectionner une zone. Double-touche = toutes les unités du même type.
PC : clic gauche / glisser = sélection, clic droit = ordre, molette = zoom, clic molette ou flèches = caméra, A = mode attaque, S = stop, Maj = file d'ordres, Échap = annuler.
Défaite : si ton Architecte meurt, la partie est perdue. Protège-le !
