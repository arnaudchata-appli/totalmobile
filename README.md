# Front d'Acier

Jeu de stratégie temps réel jouable dans le navigateur, sur PC et mobile. Tout tient dans `index.html`.

Développe ton économie (minerai + énergie), construis une base et une armée, et détruis l'Architecte ennemi.

## Jouer
Ouvre `index.html` dans un navigateur (ou via GitHub Pages).

- **Mobile** : toucher = sélectionner / ordonner, glisser = caméra, pincer = zoom, ▢ Boîte = sélection de zone.
- **PC** : clic gauche = sélection, clic droit = ordre, molette = zoom, A = mode attaque, S = stop, Maj = file d'ordres.
